# CoPMRec v3：真实 v0 的 content 排序 bad case 分析

后续状态（2026-10-04）：用户授权转向首层Max、后续Mass的候选搜索，并将其实现为从真实v0派生的v3；本报告的方向2选择及“尚未实施”是分析时历史状态。当前组件、同v0训练配置与手动命令见 [v3说明](copmrec-v3.md)，下方已复算案例与证据边界保留。

日期：2026-10-04。用户选择方向2：在当前 content 排序上分析错误并寻找优化依据。v3 当前完成具体分析，模型/loss 尚未实施；方向1不作为本轮方案。推荐参数全部可训练、不使用冻结推荐 teacher 的边界保持。

## 分析信息与结论

- Origin Skill：academic-research-suite / experiment-agent；Origin Mode：validate。
- Verification Status：ANALYZED；Version Label：copmrec_v3_content_cases_v1。
- 本轮只读现有 trace、checkpoint 输入 buffers 与原始 TFRecord；没有模型前向、搜索、训练/推理 run、W&B/Linear 写入或新增训练预算。

**已找到两类具体问题：历史商品参与下一商品竞争造成占位，以及内容相近或与历史相容的候选之间仍有判别失败。前者有可计算的排名影响，但也是 dense 对照的共有现象；后者是真正需要继续诊断的 content 学习问题。**

本轮没有证据确认“单个用户表示压缩了多兴趣”“热门偏差是主因”“内容投影损坏了语义”或某一种 loss 是唯一根因。不能据此立即加模块、换 loss 或只优化挑出的案例。

## 1. 对象与完整性

- 真实 v0：训练 `7y54j4m6`，validation-selected best step48000，testing `6dspa7e3`；Beauty/seed42。
- 完整22363名testing用户，12101商品；138名用户的目标来自33个cold商品，全部被现行cold union纳入候选。
- 重核trace MD5、checkpoint MD5及内部step/catalog，SID→商品key映射与全部真实testing目标一致，seen mask与独立扫描training得到的集合一致。
- 扫描items24个、training175个、testing175个TFRecord文件；保存逐文件SHA256。最近20件历史与运行配置一致，商品文本/品牌/类别由items记录解析，训练频次只计training原始交互。
- TFRecord自带768维embedding，实际checkpoint `content_bank`为1024维。本轮cosine使用实际1024维输入buffer，不混用768维向量；它仍是投影前描述性相似度，不是训练后的content logit或margin。
- v0 trace保存dense目标排名、候选content目标排名和Top10商品，但没有完整content分数。因此本轮不能声称量化了目标对第10名的模型分差，也没有重评分补出它。

## 2. 先分清错误环节

| 互斥分组 | 用户数 | 含义 |
|---|---:|---|
| 候选已覆盖、content Top10命中 | 1608 | 正确样本对照，含1604 warm和4 cold |
| 候选已覆盖、content未进Top10 | 853 | 本轮主要bad case：719 warm、134 cold |
| dense Top10但目标未进候选 | 97 | 搜索遗漏，不能归为content判别失败 |
| 未入候选且dense也未进Top10 | 19805 | 内容识别也不足，不能全部归因于搜索 |
| 总计 | 22363 | 与独立testing核验一致 |

719个warm候选内漏排中，96个排第11，310个排12–15，312个排16–20，仅1个超过20。**406/719=56.47%位于11–15**，候选排名中位数15，全目录dense排名中位数18。这是一批已经进入候选、仍需改善竞争判断的目标。

cold目标138个中仅4个命中；134个漏排中123个排在候选第20之后，全目录dense排名中位数741.5。它们与warm边界错误不同，分开保留；本轮不因此扩成独立cold模块。853个错误的8530条Top10竞争关系中只有5条竞争商品为cold，不能用cold占位解释warm主要损失。

## 3. 全量描述：哪些解释有依据，哪些不足

| warm用户描述 | 候选内漏排719人 | 候选内命中1604人 |
|---|---:|---:|
| 历史长度中位数 | 6 | 6 |
| 历史一级子类别数中位数 | 2 | 2 |
| 目标training出现次数中位数 | 36 | 63 |
| 目标与历史最大输入cosine中位数 | 0.9513 | 0.9474 |
| 目标与历史平均输入cosine中位数 | 0.9111 | 0.9093 |
| 目标与最后商品cosine中位数 | 0.9211 | 0.9265 |
| 最强非目标竞争者与目标同一级子类别 | 54.94% | 58.17% |
| 最强非目标竞争者与目标同完整类别路径 | 20.72% | 23.50% |
| 最强非目标竞争者training频次更高 | 83.73% | 67.77% |

这些分布反对简单解释：漏排不是普遍历史更长/类别更多，也不是目标与历史原始内容不相似。相近同类竞争确实出现，却不比命中组更集中，不能把几例发夹替换推广为全部主因。

较低频目标更常出现在漏排组，值得保留为训练曝光线索；但频次组不单调：warm频次1–10、11–50、>50的条件命中率分别60.89%、58.22%、79.26%。这些率条件于已入候选，不是全量Recall，也不证明流行度的因果影响。

进一步按同一目标商品作描述性对照：186个目标同时出现在漏排和命中组，对应400个漏排用户、829个命中用户。对每个目标分别平均，再等权平均目标差值：漏排侧最大历史cosine低0.0101、最后商品cosine低0.0155、最后商品同类别比例低11.58个百分点；更高频竞争者比例差仅−1.23个百分点。该对照控制了目标身份/频次，但仍未控制用户差异，未做显著性检验。它提示总体频次差不能直接归为用户级热门偏差，也不支持单一兴趣机制。

## 4. 具体可复查案例

案例按预先写入分析源码的确定性规则选择，不按结果选择权重。以下都来自本轮testing；同一个user ID在旧evaluation中可能有不同目标，不能串用旧排名。

### 用户827：历史商品抢占前排，目标洗发水停在第11

- 目标：item5400，**Axe Shampoo, Peace**，training27次；dense第11、候选content第11。
- 历史含洗发水、面部护理、沐浴及护发商品，最后一件是item1072 **Axe Peace Shower Gel**。
- Top1正是历史最后的沐浴露；Top3的Axe Harmony Shower Gel及Top9的Axe Peace Face Wash也在历史中。
- 目标与最后历史商品输入cosine0.9497；Top1与最后历史商品为同一商品，cosine1。

这是下一件洗发水被过去交互过的同品牌商品挡在边界的实例。在固定分数/候选下，删除排在目标前面的这3件历史商品，目标排名**确定从11到8**。该计算不证明某个新训练机制有效。

### 用户21993：高度相近的发夹，仍选错款式

- 目标：item11218，**Lovely Jewelry Crystal butterfly Hair Clips**，training6次；dense第19、候选content第18。
- 历史主要是孔雀发夹、发饰和盘发工具。
- Top1为绿色孔雀发夹，Top2为紫色孔雀发夹，Top3为爱心发夹；Top1与目标输入cosine0.9918，目标与历史最大cosine0.9702。
- Top10没有历史商品；历史只有5件，即使全删，目标也不可能由18提升到Top10。

该例存在细粒度判别错误，不能通过历史排除解释。它不证明SID碰撞：完整SID唯一；也不证明投影不可学习或真实用户只喜欢蝴蝶款，评价真值只是观察到的下一商品。

### 用户18927：历史对目标有较强内容支持，模型仍排到后面

- 目标：item3387，**Harmony Gelish High Voltage凝胶指甲油**，training30次；dense第36、候选content第19。
- 四件历史包括UV烘甲灯、Shellac底油、另一款Harmony Gelish指甲油和微针滚轮。
- Top1为Royal Nails烘甲灯，training80次；Top2为Ibd指甲油，training91次。
- 目标与历史的最大/平均/最后cosine为0.9832/0.9253/0.8635；Top1对应0.7819/0.7566/0.7819。

简单输入cosine的三项指标都更支持目标，学得的content却更偏好竞争者。这明确说明不能把投影前语义相似直接当推荐分数；目前不能分离用户读出、内容投影和曝光监督的作用。历史仅4件，全部删除也不足以把19提升到Top10。

### 用户4062：边界失败与类别噪声同时存在

- 目标：item800，**Cheeky玻璃指甲锉套装**，training45次；dense/候选content均第11。
- 历史包含OPI指甲油、Seche修复液、推甲工具、磨甲工具等；Top1为Seche面油，training268次。
- Top10的第2、3、6名商品已经在历史中，固定排名下排除它们，目标确定11→8。

该例按元数据规则被选入“最后历史类别不同”组，但从商品用途看，历史与目标都属于美甲相关工具/护理。**不能由粗类别变化直接推断兴趣切换**，类别不应当作完美真值。

### 用户905：content第1但未进候选，属于搜索问题

目标Aveeno燕麦沐浴露，training104次，dense第1，未被beam/cold候选覆盖。终排Top1是另一款Aveeno护手霜。该例用于说明本轮分组正确，不把它计入853个content漏排。

### 用户242：保留正面参照，候选子集晋升确实有效

目标Rosallini睫毛夹工具，dense第21、候选content第10，真实命中。前排是假睫毛等商品；这是90个v0 hybrid-only命中的一个。v3不能为了恢复dense目标而无差别抹掉这类子集晋升。

## 5. 历史商品竞争的最小只读鉴别

22363个真实目标均不在模型当前最近20件历史中；v0 hybrid Top1有3108次是历史商品，占13.90%。全体Top10平均包含0.757件历史商品。719个warm漏排中485人Top10含历史商品，总计979个历史条目；但这一现象也存在于命中组，不能单凭占比称其为全部错误根因。

固定已有评分和候选，仅假设终排排除最近20件历史商品。目标在历史中的数量为0，因而已有命中不会因此丢失。当前保存完整目标rank和前10项，可计算严格排名上下界：

```text
目标原排名r；Top10中已知在目标前的历史商品数a；
Top10之外的历史候选数b，未知前置位置最多max(0,r−11)。
新排名 ∈ [max(1,r−a−min(b,max(0,r−11))), r−a]。
目标未入候选仍视为缺失。r≤11时，目标前的条目已完整保存，排名变化可精确确定。
```

这不是新预测输出，不包含完整更新Top10，也不是置信区间；没有重排序完整候选分数、重跑decoder或按目标设计推理规则。

| 同规则诊断 | v0 hybrid | v0 dense | LIGER dense |
|---|---:|---:|---:|
| 原Recall10 | 0.071904 | 0.072218 | 0.071413 |
| 可确定新增命中至少 | 127 | 143 | 120 |
| 新增命中数学范围 | 127–167 | 143–461 | 120–464 |
| Recall10数学范围 | 0.077584–0.079372 | 0.078612–0.092832 | 0.076779–0.092161 |
| NDCG10数学范围 | 0.042814–0.043390 | 0.043092–0.047434 | 0.042659–0.047357 |

v0的127个确定恢复含124 warm、3 cold，相当于719个warm漏排中至少17.25%可由这一固定候选资格干预恢复。它不能解释全部warm漏排，更不能恢复97个目标缺失。

**同规则也明显帮助dense对照，不能比较两个下界的大小判优，更不能以处理后的v0对比未处理的LIGER宣布v3收益。**这是当前样本的下一商品评价与历史候选资格现象，不是新训练结果。当前正式协议仍允许历史商品进入推荐；本轮没有改变它，也不把排除历史推广成允许重复购买场景的一般规则。

## 6. 对 v3 方向2 的具体判断

1. **首先明确历史竞争的比较口径。**已经有完整样本和排名界的正面依据，值得在所有对照中按相同规则进一步核验。若以后采用排除历史，应单独声明协议变化并同步baseline；如果保持原协议，应评价模型是否能减少对过去商品的错误吸引。两者都不能称为仅CoPMRec的新贡献。
2. **随后聚焦剩余的warm竞争判别。**719个warm案例中406个位于11–15，存在细粒度商品差异及输入语义支持未转成正确排名的实例；这支持继续分析content监督/表征，尚不足以直接选某个新loss或结构。
3. **保护已有正确命中和子集晋升。**以1608个命中为正面参照，并报告全部位置变化；不只修复几个案例，也不将历史cosine/类别/频次阈值直接部署为gate。
4. **保留边界。**cold正例缺少training曝光、搜索遗漏和全目录识别不足分别记录，不将所有错误包装成一个可由终排解决的问题。

原失败阶段保持关闭，v2不恢复。v3本轮只完成方向2问题定位，新增正式实验预算0；尚未授权新训练或推理，模型/loss未定案。现有证据不能确定encoder末位读出还是商品投影是主要根因；完整模型分差未保存，这一未知明确保留，不穷尽性重跑。
