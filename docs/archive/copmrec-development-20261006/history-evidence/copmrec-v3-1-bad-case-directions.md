例如 user353、item3101：dense第15，v3最终第8；v3.1目标仍在候选里，新增4个dense Top10商品后排到第11。增加召回不能直接修复这种损失。

这里的代价来自候选成员变化与固定内容排序的组合，不是v3.1改坏了内容分数。下一方向必须评价最终命中和NDCG及当前81个增量命中的保留，不能只优化dense遗漏。强制纳入全部dense Top10再content终排，会消除大部分候选筛选的增量空间；当前不采用该策略，也不恢复已关闭的v2排序head/loss路线。

## 首选方向：后根使用最佳完成路径的概率上界

只修正第2、3层搜索优先级。保留：v3.1首层Max选择、root包络先验、局部生成/Mass混合分布、checkpoint/alpha、单次beam20和content终排。暂不命名新实现版本，尚未实施。

记 `S(p)` 为v3.1在前缀p的原累计分数（已含第二层一次root补正），后续合法孩子生成分布为g、内容条件分布为qC，alpha为同一checkpoint常数。原局部混合为：

```text
qMix(child | p) = (1-alpha) g(child | p) + alpha qC(child | p)
```

利用每条合法生成概率 `g≤1`，每个后续边可获得无需额外模型前向的概率上界：

```text
u(child | p) = (1-alpha) + alpha qC(child | p)
qMix(child | p) ≤ u(child | p) ≤ 1

B(完整SID) = 0
B(p) = max_合法child [ log u(child | p) + B(child) ]
```

B是最佳完成SID的剩余log概率上界，来自合法树上的逆序max递推。它不是新的归一化分布，不用 `u` 替代模型局部概率。对任意后代商品，其真实剩余混合log概率≤B(p)。

搜索优先级为 `F(p)=S(p)+B(p)`，仅从长度2的SID前缀开始使用；第1层仍使用原选择分数。返回给beam的增量采用势差，使原目标保持：

```text
第1层：原v3.1输出，H(root前缀)=0
第2层：原局部logqMix + 原root correction + B(child)
第3层：原局部logqMix + B(child) - B(parent)
第4层：原局部logqMix + 0 - B(parent)
```

因此对同一固定完整路径，所有B势差最终相消，完整SID累计分数严格等于v3.1原分数；搜索过程会保留不同前缀，最终候选仍可能改变。完整路径分数一致不意味着预测一致，也不保证原命中均保留。

单商品前缀后续每步只有一个合法孩子，生成与内容条件概率均为1，所以B=0且为精确值。多商品前缀至少有一次分流，有限alpha>0时B<0；比较前缀时计入其后续分流，避免直接把整组前缀质量当作某个完整商品的质量。24个案例体现这个适用结构，但缺少扩展阈值，无法保证足够改变实际beam选择。

### 数学性质与边界

- alpha=0时B=0，恢复原生成侧搜索；alpha=1时 `B(p)=max_descendant c(i)-logsumexp_descendant c(i)`，是精确内容最佳完成log概率。
- 真实alpha=0.668786下仍为剩余混合概率上界；没有额外lambda、quota或学习模块。上界可能偏松，因为用1替代未知未来生成概率。
- 第2层之后满足局部一致性：`logqMix(child|p)+B(child)≤B(p)`。首层admission与第二层root补正是既有边界，不声称整个root初选等价于全目录最优搜索。
- 有限beam20的剪枝仍可能丢失目标；“上界成立”不等于全局最优、推荐效果保证或消除81个遗漏。
- 候选终排使用内容分数。完整混合路径分数不变，只隔离“中间搜索误差”的改动；最终Recall/NDCG仍需实际推理评价。
- 只影响中间状态，不能在给定同一第3层frontier时直接改变第4层的最终完整路径相对分数；末层10个遗漏不保证直接恢复。

300个随机合法树、900个数学条件检查（alpha=0/当前值/1），核验31950条固定路径和36936个前缀：完整路径分数相消误差≤1.78e−15，上界/一致性违反为0，alpha=1精确完成式误差≤2.22e−16。这些是公式验证，不是实际模型、beam或性能实验。

同时检验了简单 `alpha*(Max−Mass)` 近似：在两后代等内容、未来生成概率为1的例子中，该估计为−0.463567，真实混合log概率为−0.407056，前者不是合法上界。因此首选上面的mixed completion递推，避免把近似当作A*保证。

### 实现连接点与成本估计

RootEnvelopeProcessor已提供Max首层、root包络和后续Mass表；第2/3层Mass parent/child的差即qC的log概率。可在现有表上用 `mix_log_probs(generation_log_prob=0, content_log_prob, checkpoint_bias)` 计算边上界，再按合法parent反向scatter-max得到B，不必增加生成forward或第二轮beam。

需要两个batch×前缀表（长度2/3，共7342+10999个合法前缀）；batch32、FP32约2.24MiB永久表，另有临时张量。运算规模约为batch×目录节点数；当前只是成本估计，未测真实延迟。完整checkpoint与预测链路继续用统一入口和共享writer。

未来若获准实施，trace须分开记录局部混合概率、原root补正、B、补正后的搜索增量/累计优先级和原完整路径分数；字段不能继续混称条件概率。目标标签只用于观测，不参与B或搜索选择。

## 相关工作定位

[LIGER](https://arxiv.org/abs/2411.18814) 将生成检索与dense检索结合；本方向围绕其内容辅助候选在固定beam预算中的前缀可达性，不新增终排模型。[NeuroLogic A*esque](https://aclanthology.org/2022.naacl-main.57/) 使用未来成本heuristics改进受约束生成，说明以完成估计参与beam优先级是已有方法思想。[Best-First Beam Search](https://aclanthology.org/2020.tacl-1.51/) 研究单调打分下的安全剪枝与搜索效率；不能把其速度或搜索性质直接转述为推荐收益。

本方向不是首次提出lookahead/A*或内容Max/Mass。可形成的论文叙事是：区分root admission、前缀整组质量与完整商品价值，通过匹配checkpoint的搜索机制实验解释可达性与最终损益；完整贡献仍需效果和保留代价证据。

## 路线判断与最小后续验证建议

1. 核心假设：同预算内容条件前缀搜索可以降低可识别目标的遗漏，并取得最终净增量。v0正式矩阵支持有限候选修复，未建立相对dense稳定增量；v1/v1.1有界验证未建立完整收益，v2完整Testing负向且排序路线关闭。v3首层有效但整体未晋级，v3.1同checkpoint获得部分后层修复与小幅点估计增益，CI跨零。当前支持机制层，效果层仍未过门槛。
2. 具体未决项：前缀累计概率未计入未来分流是否造成可减少的剪枝损失。24例的结构和B上界性质给出正面依据，允许提出一个最小鉴别对照；不是因为尚未排除其他原因而扩展机制。
3. 若后续明确获准，建议仅一次新decoder完整推理、零训练，复用best43500，与已有zznw291t比较。首层/root规则、参数、alpha、dense排名、用户/输入、beam20必须相同；在固定同一完整路径上原累计目标必须相同。禁止同时改变局部概率或添加配额。成本为既有同规模单卡推理加小量表运算，实际耗时未验证。
4. 验证同时覆盖81个高内容遗漏、其中24个结构性案例、当前81个超dense增量命中、原首层47/29恢复、全体新增/丢失和共同位置变化。以最终NDCG10为主、Recall10及保留代价共同判断，不以结构案例恢复率替代最终效果。
5. 候选修复与最终净收益同向改善支持本机制继续开发，但不自动授权重训或多seed。未减少相关剪枝/只挪到后层、或损失抵消最终收益则收缩或停止此完成上界方向，保留v3.1。局部改善而总体未改善或CI跨零，记录不确定，不自动增加参数扫描、替代机制或预算。
6. 本次用户授权是保留基座与探索。上一阶段唯一推理已消费，剩余实际预算0；上述一次推理仅为待授权建议，新训练预算0，本轮新运行0。Testing已用于开发分析，未来比较亦须披露开发证据范围。
