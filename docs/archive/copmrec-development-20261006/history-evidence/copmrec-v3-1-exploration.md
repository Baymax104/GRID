## Max与Mass累计分数的关系

记商品content logit为c_i，根r的最佳后代分数为M_r=max(c_i)，质量为L_r=logsumexp(c_i)，Z_X=logsumexp_r(M_r)。只考虑content分支、alpha=1的分析极限，v3路径概率为：

```text
log q_v3(item i)
= [M_r − Z_X] + [c_i − L_r]
= c_i − (L_r − M_r) − Z_X
```

所以v3的完整content路径不仅由商品分数决定，还包含root相关的D_r=L_r−M_r。它是Max/Mass拼接的真实数学性质，不是实现bug；实际alpha约0.6688，混合概率不能直接用上式替代。

73个第二层遗漏中，有21例同时满足“目标为该root最强content商品”和“目标二层分支仅有一个后代商品”。此时已有trace的q_content(target child|root)=exp(M_r−L_r)，可以精确得到D_r=−log q，而不运行模型。这21例的D_r中位数1.8328、均值1.7887；对应中位数约6.25倍的质量/最大项比例。user21319为1.53964。该事实支持检查跨root的分数标定，但没有证明它解释全部114个失败。

500棵随机小树、2500条路径的数学等式和后根max势差等式均通过，最大误差约1.78e−15。这些是公式核验，不是推荐效果或候选恢复结果。

## v3.1首选候选：首层Max选root，后续保留Max并结合Mass路径优先级

首选定义为解码修订，训练模型仍使用v3 checkpoint。最小目标是改变跨root的后续竞争，不改变首层处理、局部Mass混合分布或content终排。

在第1步用同一生成分布g、alpha，同时获得两个已有意义的root混合分数：

```text
r_X(r) = log[(1−alpha)*g(r) + alpha*softmax(M)_r]
r_M(r) = log[(1−alpha)*g(r) + alpha*softmax(L)_r]

首层：仍只按r_X选择相同的20个root。
后续root路径优先级：
  e(r) = max(r_X(r), r_M(r))
  r_E(r) = e(r) − logsumexp_all_legal_roots(e)
第二步仅补正一次：delta(r) = r_E(r) − r_X(r)
后续继续原Mass混合概率，并按修正后的累计分数保留beam20。
```

直接将r_X替换成r_M会压低Max救回的某些root，所以推荐用max保留两路较高的root优先级。归一化常数对同一用户所有root相同；归一化前e(r)≥r_X(r)。这不保证原有目标最终都保留，其他root提升仍可能产生挤占。

| 项目 | v3 | 拟议v3.1 |
|---|---|---|
| 首层选择分数和root集合 | r_X、beam20 | 完全相同 |
| 后续局部内容聚合/生成分布 | Mass / 原生成分布 | 完全相同 |
| 用于后续累计竞争的root分数 | r_X | r_E |
| 终排 | content | content |
| checkpoint / alpha / 内容参数 | best43500 / 0.668786 | 复用相同字节 |
| 额外head、loss、训练 | 无 | 不新增 |
| 候选/解码预算 | 单次beam20加全部cold | 相同 |
| 新的权重或配额 | 无 | 无 |

补正是同root所有子分支共享常数，父节点内部的局部分支排序不变；它改变跨root分配。有些局部第2–4名分支因此可能获得机会，仍不能覆盖所有低位分支。root优先级包络归一化只定义新的搜索路径先验，不宣称做过标签意义上的概率校准。

这个方案的可反驳预测：同checkpoint、完全相同的第1层frontier下，第2层强content目标的遗漏减少，2–4层总遗漏和最终净收益同步改善。若只将失败推到后层、或挤占原命中导致最终净损失，则否定当前补正形式，保留首层Max。

实现时可复用现有ContentPrefixProcessor已计算的max表与ProbabilityMixtureProcessor的Mass表；cache根层r_X/r_M，在第二个SID决策按root token施加一次补正。额外计算为根层聚合与小表读取，不需另一轮beam搜索。HF返回的补正增量不是条件log概率，trace必须分别记录root admission、root path prior、calibration delta和累计search score；不能把它直接写成旧target_mixed_log_prob。checkpoint训练版本v3与解码版本v3.1分开记录，不把v3.1称为已经重新训练的模型。若以后决定训练，需要另行说明目标是否变化。

500组随机root分布、2000个数学条件核验：包络归一化误差≤4.44e−16，补正一次的累计等式误差≤1.78e−15；全局包络归一化常数位于[0,log2]，同父局部rank不变。没有运行实际模型或HF beam，尚无该候选的性能数据。

## 备选与取舍

| 候选 | 对现有证据的对应 | 当前取舍 |
|---|---|---|
| 每root保留一个分支 / 通用多样化 | 只直接对应第2层10个root灭失；63例root仍在 | 不作为首选 |
| 第2层也改Max，即[max,max,mass,mass] | 会同时改变局部q、分支排序与后续累计；可能把失败移到第3层 | 保留为备选，不与首选并行开跑 |
| 后根加入max后代势差lookahead | 46例所有保留兄弟最佳内容后代更弱；可惩罚偏离强后代的分支 | 有针对性，但会改局部分支rank和分数强度，先不增加权重选择 |
| 上述root路径优先级补正 | 数学上明确分离Max初选与后续Mass竞争，局部规则不动 | 首选一项可鉴别改动 |

v3现有103个超出自身dense Top10的增量命中中，102个warm、1个cold，目标dense位置11–45、中位数12；57个与更高content Top10商品同root。任何过强的content保护都可能挤掉这些收益。尤其不能把所有dense Top10商品强制加入后再用同一content终排宣称生成增量：包含完整dense Top10时，通常会直接返回dense Top10（相同tie口径下），失去候选筛选的增量空间。

## 相关工作定位与证据

[LIGER原论文](https://arxiv.org/abs/2411.18814) 将生成检索与dense检索结合；这里研究其候选前缀搜索在固定预算下的内容可达性，终排沿用内容分数。组件相似用于定位，不把一般Max/Mass或beam思想宣称为首创。

[Li等人的父分支多样化解码](https://arxiv.org/abs/1611.08562) 通过兄弟排名惩罚鼓励来自不同父节点的假设；当前多数失败的父节点仍有分支，因此当前首选是已有父节点的路径优先级与局部竞争机会，不直接照搬多样化作为充分解释。

[NeuroLogic A*esque](https://arxiv.org/abs/2112.08726) 使用未来成本启发式支持lookahead；这为max后代势差备选提供方法定位，不提供该备选在推荐中的效果证据。我们的root补正候选未运行，贡献表述应等待机制与最终指标支持。
