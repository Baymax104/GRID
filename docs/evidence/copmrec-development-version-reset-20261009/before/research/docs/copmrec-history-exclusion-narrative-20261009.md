# CoPMRec历史排除的论文定位建议

2026-10-09。用户询问论文方法应采用还是不采用历史排除，并认为无排除版本仍有增益、Recall@10接近。本记录为研究建议，不更改已冻结v5.3实现、正式评价协议、主指标、实验有效状态或启动授权。

## 建议与方法边界

建议核心方法定义不依赖最终历史商品排除，以双方均不排除历史的dense结果承载训练表示与推荐质量的匹配比较；历史排除作为可选部署策略，明确报告其规则与固定模型开关结果。若主版本最终改为无排除，应标记为明确的部署协议调整，不能将现有九单元开启排除的主矩阵改名为无排除结果。

这是叙事与方法边界的建议，不是根据Testing重新选模型、检查点或主指标。NDCG@10仍是原主指标，Recall@10仍按原口径报告；不能将较有利的@5结果追改为预设主指标。

## 当前全部相关证据

- 正式完整方法主矩阵9/9及匹配原LIGER hybrid已核验，三个数据集/三个训练seed。实际流程为CoPMRec full-catalog dense并排除输入历史，原LIGER为hybrid及原历史政策。它支持完整流程的既有结果，不单独确立相同dense下的学习优势。
- M3五臂/250k及M1/M2/M3机制证据已完成，唯一Beauty/seed42。A4替换对照具有当前单元方向证据，但M/native独立增量未充分确立；固定残差依赖不等于重训净增量。现有M3最终评价保持历史排除，其数值不能改称无排除消融。
- BMX-147双方均开启历史排除的dense内部对照：Full−LIGER的NDCG@10为+0.00161752，区间包含0；四项总体区间均包含0。
- BMX-148固定CoPMRec仅切换最终排除：NDCG@10开启−关闭为+0.00629025，相对关闭+16.49%，CI[+0.00574222,+0.00687142]。
- BMX-149固定LIGER dense仅切换最终排除：NDCG@10开启−关闭为+0.00642487，相对关闭+17.66%，CI[+0.00583263,+0.00703716]。历史排除的观测作用可以迁移到原有LIGER模型，现有证据不支持将它称为CoPMRec独有的学习机制。

## 双方均不排除历史的收益与边界

Beauty/seed42、相同22363用户，各自原own-best，完整目录dense、FP32、稳定排序。百分比以LIGER dense为分母。

| 指标 | CoPMRec−LIGER相对点差 | 绝对差95% pointwise CI |
| -- | --: | -- |
| Recall@5 | +6.73% | [+0.00013415,+0.00558959] |
| NDCG@5 | +10.66% | [+0.00095453,+0.00477921] |
| Recall@10 | -0.69% | [-0.00371149,+0.00272772] |
| NDCG@10 | +4.81% | [-0.00006695,+0.00365801] |

可以描述当前单元的前列推荐质量改善：Recall@5和NDCG@5区间位于零以上，NDCG@10点差为正，Recall@10点估计接近。Recall@10未见明确差值方向，不是等价检验；区间包含零不能证明严格持平。相近的命中率也不意味着两方法命中相同用户；没有此配对分解前，不能断言收益仅由相同命中目标前移产生。

上述用户bootstrap未校正多重比较，不覆盖训练seed变化；正式完整方法的多seed证据不能自动转移为无排除dense条件的多seed证据。当前不宜写成跨数据集、跨seed稳定优于dense baseline或全面提升所有指标。

## 可采用的论文组织

Methods描述内容条件前缀训练、共享残差与实际dense评分，并将最终历史排除注明为可选部署步骤。Experiments分别呈现原完整方法比较、匹配dense内部比较和固定模型排除开关；学习机制与部署策略的观测收益分开报告。建议表述为“在Beauty/seed42的匹配dense对照中，无历史排除时CoPMRec取得更高的Recall@5与NDCG@5；NDCG@10点估计更高，而Recall@10差值仍不确定。”

当前Introduction仍将mixture写成beam推理时的路径分配机制，与正式dense部署不一致。无论历史排除如何定位，都应先将该叙述对齐实际方法；移除排除不能修复beam机制与实际部署的错位。原LIGER论文将hybrid描述为生成候选上的dense检索，故内部full-catalog dense与原hybrid须继续区分，不因这次比较替换原baseline。

## 当前决策与预算

核心假设是CoPMRec学习流程在匹配候选和历史规则下仍有推荐质量增量。无排除@5提供当前单元支持，@10证据不确定；未出现完整机制被否定的证据，但不支持全面稳定优势。关键实现疑点已经由checkpoint/input/source/output和前缀过滤一致性检查收敛，无需再训练或追加开关实验来完成上述有边界的叙事。建议新增训练0、Testing0，不自动展开其他seed/数据集，不重置原M3预算，不将本建议视为已批准正式部署协议切换。
