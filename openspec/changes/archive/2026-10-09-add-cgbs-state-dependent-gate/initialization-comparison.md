# A 的完整内容条件均值与残差码质心：数学及产物核查

日期：2026-09-17。用户已决定以A为主方法起点，当前C/D/E退出主线。本轮只核查既有代码、量化器与内容产物，不修改生产代码、不训练推荐模型、不启动完整量化推理或diagnosis。

## 核心结论

二者存在实质区别，且主要集中在第2、3层。第一层在相同原始归一化空间中几乎一致；后两层的完整内容条件均值表示使用该token的物品总体内容，残差质心表示当层的归一化剩余量。真实Beauty码本的静态几何支持这一差异。

这足以提出一个明确问题：生成token应继承完整内容的条件表示，还是继承量化残差的代表向量？但尚不能证明A优于残差初始化，也不能证明A现有收益来自后两层。后者是下一步最需要排除的替代解释。

## 1. 两种定义

设物品原始内容向量为z_i，SID第l层码为k_l(i)，同层使用码k的物品集合为I_lk。当前A先进行全目录中心化PCA和逐物品L2归一化：

```text
x_i = normalize((z_i - m) P)
mu_lk = mean(x_i | k_l(i) = k)
e_lk = scale_l * mu_lk
```

P为1024→128的固定PCA基；scale_l按该层随机embedding表和全部已用码均值向量的整体标准差匹配。初始化后参数正常训练，最后去重层不作内容初始化。

这里的条件仅为“层级及token值”，不包括用户、交互频率或完整父前缀。同层同码在多个父前缀下共用一行。均值是对目录物品等权统计，不能解释为行为偏好加权或严格意义上的无热门偏置。

当前RKMeans则执行：

```text
r_0 = z_i
u_l = normalize(r_l)
k_l = nearest_centroid(u_l, codebook_l)
r_(l+1) = u_l - c_(l,k_l)
```

码本质心c_lk近似该码对应的归一化残差u_l的均值。有限训练后的质心不保证严格等于全目录经验均值，因此本文用“近似”而非恒等式。

对应源码：`src/recommendation/tiger_catalog_grounded/module.py::_initialize_tokens`、`catalog.py::PrefixCatalog`、`src/quantization/rkmeans/residual_kmeans.py::forward`、`kmeans_layer.py::KMeansLayer`。

## 2. 为什么第一层接近，后几层不同

在相同预处理和相同分组下，第一层没有前序残差消减，其质心本来就在概括完整输入。因此第一层不能仅靠“条件均值与质心名字不同”构成区别。

对于不逐层归一化的普通残差量化，可以写：

```text
z = sum(previous selected centroids) + current residual
E[z | k_l=k] = E[previous centroid sum | k_l=k] + E[current residual | k_l=k]
```

但当前实现每层重新归一化，上式不能原样套用。令q_l为已选质心，s_l=||u_l-q_l||，则准确关系是：

```text
u_0 = q_0 + s_0*u_1
    = q_0 + s_0*q_1 + s_0*s_1*u_2
```

后续层的贡献包含物品相关的尺度乘积；取条件期望时不能随意将这些尺度和残差向量的期望拆开。本轮在真实目录上以float64核验了逐层加权恒等式。

A还额外包含中心化PCA和逐物品归一化；均值与这个非线性变换不交换。因此“完整内容均值等于残差质心加一个父节点均值”不是当前A的正确实现公式。

直观上，残差码描述“在已有量化表示之后补充什么”；完整内容均值描述“使用该码的物品整体是什么样”。前者保留量化的逐层分工，后者可能带入与前序码相关的整体内容，也可能将不同父前缀下的物品混合。Transformer已有上下文，不能直接断言某种表示必然更适合推荐。

## 4. 几何统计

首先在原始1024维单位向量空间比较，消除A的PCA和再次归一化影响。所有数值对该层256个已用码等权平均：

| 层级 | 完整输入条件均值与残差质心的方向余弦 | 当层经验残差均值与码本质心的方向余弦 |
| --- | ---: | ---: |
| 1 | 0.99985 | 0.99985 |
| 2 | 0.15305 | 0.99659 |
| 3 | 0.09798 | 0.99327 |

第一列显示后层“完整物品代表量”与“残差代表量”明显不同；第二列确认质心确实贴近当层经验残差均值。原空间方向可能受共同均值影响，因此同时给出去共同平移后的128维比较，不能只挑选较小余弦来夸大区别。

将残差质心投影到A的同一PCA基；两个码表各自去掉跨码均值后比较方向与余弦邻域，避免整体平移和统一尺度主导结果。这是几何核查，不是训练初始化配置，也不是最近LLM论文的完整复现：

| 层级 | 对应码平均余弦 | 码间余弦排序Spearman相关 | 最近10个码邻居重合率 |
| --- | ---: | ---: | ---: |
| 1 | 0.99250 | 0.98240 | 94.45% |
| 2 | 0.72495 | 0.38684 | 31.09% |
| 3 | 0.63983 | 0.26789 | 21.37% |

因此后两层并非仅范数不同，码之间的相对几何关系也改变。统计覆盖全部目录与已用码，不是推荐指标或统计显著性检验。

另一个结构事实：同码跨完整父前缀的数量，中位数在第2层为21.5、第3层为36，最大分别106、137。A的深层条件均值跨这些父上下文汇总，不能将其描述为父前缀专属表示。

## 5. 对A和论文的含义

### 支持的结论

- 当前A并非逐层直接复制残差码本。
- 第一层与常规质心先验非常接近，后两层保留的代表量和几何结构不同。
- “量化重建用的代表量”与“生成token初始化用的代表量”之间存在可研究的选择，不需要恢复C的在线分支。

### 尚未支持的结论

- 完整内容条件均值一定比残差质心有更高推荐收益。
- A当前+6.43%的初始化增益主要来自第2、3层，而非第一层或预处理。
- 多父前缀混合必然有害，或者引入父前缀模块必然有效。
- 条件均值的新名字足以形成论文创新。

均值mu在同码常量代表量中最小化内容空间的平方重建误差，是条件期望的基本性质：E||x-e||²=E||x-mu||²+||mu-e||²。这个性质针对未缩放的mu及平方误差，不保证经标准差缩放后的embedding最优，更不等同于推荐NDCG最优。不能用构造目标上的必然优势代替推荐实验。

## 6. 与最近工作的关系

[Preserving Item Semantics for Free](https://arxiv.org/html/2608.07816v1#S2) 同样采用逐层归一化残差量化；其[第4节](https://arxiv.org/html/2608.07816v1#S4)把残差码本质心经维度映射、均值平移后赋给SID token，去重token随机初始化。本轮核查没有发现可把“逐层归一化”作为我们独有设计的依据。

能够明确区分的是：A从完整物品内容重估各层的条件代表量，而该工作直接使用量化质心。其是否构成有价值的新贡献，取决于是否在匹配条件下显示后两层区别带来可重复的推荐收益。本文不照搬其LLM语义恢复、流行度或冷物品结论。

## 7. 最小后续判别建议（尚未实施）

保留已有A作为参照，最多提出两个针对性条件进入下一次规格讨论：

1. **第一层内容初始化，后两语义层随机初始化**：判断A的效果是否主要由第一层解释。其他参数、去重层、损失、预算不变。
2. **第一层保留A，后两层改为既有残差质心初始化**：直接检验已发现的深层代表量差异是否有推荐价值。

第2项必须先锁定投影、平移、范数和标准差处理。当前A是“逐物品变换再求均值”，质心方案是“码本向量再映射”，不能声称只用了相同PCA就消除了全部预处理差异。它首先是两套可部署初始化的匹配比较；若要单独归因代表量，需要进一步明确变换口径，不能混称为原论文完整复现。

若A不优于第一项，应优先简化A；若A在后两项上均有可辨认收益，才有依据把深层完整内容代表量作为机制贡献候选。均不预设结果，不扩展在线分支、训练目标或新模块。新训练仍须用户另行决定并手动用GPU0/1启动。
