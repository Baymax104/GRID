# CGBS 复杂分支的调参与结构修正评估

## 结论与研究范围

2026-09-16：可以研究有针对性的修正，但现有证据不支持扩大容量或开放 sweep。优先判断内容分支是否损害共享主干训练、是否在推理时混合过强；只有内容互补信号存在且已定位剩余缺陷时，才新增模块。

当前最优先的结构候选是**仅阻断辅助 item CE 对共享编码器的梯度**，保留其对内容查询头的训练。它不是已验证方法，也不是新的论文贡献声明。本次只做代码/数学分析与原始论文核查，未实现该候选，未启动任何训练或推理。

本轮在线检查 `content_init_aux/content_init_full` 的 inference run 列表为空；C/on 与 C/off 的冻结结果尚未取得。记录位于 `tmp/cgbs_mechanism_training/inference_status.json`。训练事实使用已经核验的 A=5g3wpbg7、B=z98fozox、C=k6jvoo2v，详见 training-outcome.md。

## 已有事实与候选解释

- A best NDCG@10=0.042569727，B=0.040364187，C=0.041390747；B/A−5.18%，C/A−2.77%，C/B+2.54%。同初始化、同训练预算、同上游 Artifact。
- B 相对 A 的主要干预是增加辅助内容监督，因而共享表示训练受到影响是优先候选解释；单种子对比不能排除优化随机性或其他任务不匹配，尚不能直接称为梯度冲突。
- C 比 B 好只能支持整个混合训练/推理方案的相对表现；不隔离在线推理作用，亦不代表超越 A。
- 当前没有“多原型不足”“动态门控必需”“前缀查询容量不足”的项目证据。

## 源码指出的三处具体耦合

### 1. 辅助监督与共享编码器

`module.py::_query` 对 encoder hidden states 做 masked mean pooling、MLP、L2 normalize。`training_step` 的生成与辅助 CE 使用同一个 query，没有 stop-gradient：

\[
L=L_{gen}+\lambda L_{item},\quad
\nabla_\theta L=\nabla_\theta L_{gen}+\lambda\nabla_\theta L_{item}.
\]

其中 theta 为共享 encoder 等实际受两个目标影响的参数，当前 lambda=0.1。B 最后记录 L_item≈8.503、L_gen≈1.874，加权辅助标量≈0.850，所以“权重0.1”不能解释为“只占10%的影响”。损失标量比例也不是梯度范数比例，未测量梯度就不能声称辅助目标支配优化。

辅助 CE 用固定内容向量识别下一个具体 item，生成目标用 SID 分层预测。两者可能互补，也可能因内容相似与行为偏好不一致产生不利迁移。

### 2. 混合分布也改变主分支的训练梯度

当前 C 对 P=(1-alpha)p+alpha q 计算生成 CE；p 是合法 token 分布，q 是内容分布。固定 q 和 alpha，针对 token logits z：

\[
\frac{\partial[-\log P_y]}{\partial z}
=\frac{(1-\alpha)p_y}{(1-\alpha)p_y+\alpha q_y}
\frac{\partial[-\log p_y]}{\partial z}.
\]

该式是对当前概率混合的解析推导，不是实验结果。当 q 对目标支持较强时，token 路径梯度变小。举例 p_y=0.02、q_y=0.2、alpha=0.22 时系数约0.262；这些数值仅为说明例子，不是训练统计。

因此，C/off 的底座已经受混合损失训练，不能把它当作独立训练的 A/B。以上是对固定内容分布的 token-logit 偏导；共享编码器的总梯度还包含 query 和其他路径，不可将该系数当作所有参数梯度的缩放。

这提供“生成学习被分支分担”的候选解释，但无法据此认定学习受损，混合责任分配也可能有益。

### 3. 温度与强度是不同问题

- lambda 控制辅助监督。
- alpha 是每层一个可学习标量，对所有用户共享，初值0.1、上界0.5；C 末期均值约0.223。它不是用户级可靠性判断。
- temperature=0.1 同时用于 full-catalog item CE 和前缀内容 mass。直接调整它会同时改变查询训练、梯度尺度及推理分布锐度。

因此不同时调 lambda/temperature/alpha/prototypes。若进行纯推理温度校准，需要把推理温度与训练契约显式分离；现有 checkpoint 契约不能随意修改。

## 优先候选：辅助梯度隔离

令 h=Pool(Encoder(history))：

\[
q_{gen}=Normalize(g_\phi(h)),\qquad
q_{aux}=Normalize(g_\phi(stopgrad(h))).
\]

仅将 L_item 的输入换成 q_aux；生成混合继续使用 q_gen。保持 lambda、temperature、原型、初始化、预算不变。

这样辅助损失仍更新 phi，但其梯度不再进入共享 encoder；生成目标仍按原路径更新 encoder、query head、decoder 与混合系数。**不能直接对现有唯一 query 执行 detach**，否则会阻断查询头学习；也不能不加区分地在唯一 `_query` 输入处 detach，因为那会同时切断生成内容路径的 encoder 梯度，改变两个因素。

这是对单一梯度路径的干预，不增加参数。它无法保证 A 的训练轨迹不变，因为 C 的生成损失仍为混合 CE。

若在 B 上隔离辅助梯度，理论上主干可保持 A 的生成目标；在相同输入、随机状态、无全局梯度裁剪耦合等条件下，可通过小型梯度/更新等价测试验证，无需为这个恒等性另跑完整 B 训练。

优先级根据 C/off 结果决定，而不是立即启动：

| 冻结结果 | 更值得检验的解释 | 下一动作 |
|---|---|---|
| C/on优于C/off，但C/off明显低于A | 分支对当前模型有作用，但训练后的底座不足；与训练干扰解释相容 | 优先一次辅助梯度隔离修正 |
| C/off达到A附近或更好，C/on却下降 | 推理混合造成损失的证据更直接 | 优先冻结模型的alpha敏感性，不先改训练 |
| C/on与off都差且差异很小 | 尚无可利用分支收益 | 不加门控/注意力；默认结束本复杂分支修复 |
| 以后精确集合聚合可靠胜过原型，且置乱对照无同样收益 | 定位到近似误差 | 才允许针对近似做修正 |

这些是决定下一干预的信息，不是完整因果识别。

## 调参和新增模块的选择

| 方向 | 判断 | 必要约束 |
|---|---|---|
| 辅助权重0.1降低 | 可作为梯度隔离的替代诊断；优先级次于明确路径隔离 | 最多预先固定一个较小值，例如0.03；它是探针不是推荐最优值。若比较在线机制，必须有同lambda的辅助-only对照，不能用lambda0.1的B替代 |
| 冻结alpha强度校准 | 若off提示混合损害则优先 | 只做少量预设缩放；在独立校准划分选系数，再评估，不能以同一开发集调参峰值宣称确认。改变alpha会改变beam路径，不能只重排缓存最终列表 |
| 动态门控alpha(u,p) | 条件候选 | 先证明分支有显著互补样本、误伤可由推理可见特征预测，并超过最佳固定系数。用标签选择A/C的oracle只说明潜在空间，不是可部署收益 |
| 前缀条件查询或多兴趣注意力 | 暂缓 | 当前query为历史均值且跨前缀复用是结构事实；不能因此认定其容量不足。先证明查询缺陷再加表达能力 |
| 增加原型/PCA维度 | 暂缓 | 先用精确参考区分近似误差与内容本身无效；M=4对M=1现有优势不足 |
| PCGrad/动态任务权重 | 暂缓 | 先测共享参数的梯度方向和加权范数；复杂优化器不应替代简单梯度路径干预 |

如果进行梯度诊断，应比较固定真实训练batch上的共享encoder梯度余弦与 lambda*norm(g_aux)/norm(g_gen)，并保留按层统计；一次或末期checkpoint的负余弦只能提供局部支持，不能解释整个训练史，更不能直接推出主方法必要性。正式诊断和训练仍由用户手动启动。

## 原始研究核查及对本项目的约束

这是针对当前问题的原始来源核查，不是穷尽式系统综述。

- [Yu et al., Gradient Surgery for Multi-Task Learning, NeurIPS 2020](https://arxiv.org/html/2001.06782v4)：讨论梯度方向冲突、量级差异与曲率共同产生的不利影响，提出PCGrad。支持调查训练干扰，但不证明本项目存在该机制，也使“采用梯度手术”本身缺乏新的方法独创性。
- [Yang et al., Unifying Generative and Dense Retrieval for Sequential Recommendation](https://arxiv.org/html/2411.18814v2)：LIGER同时使用内容对齐与SID预测，并在输入和检索设计中利用内容。说明不能从本项目B负结果断言联合内容监督普遍无效；我们的B不等同完整LIGER。
- [Conditional Memory Enhanced Item Representation for Generative Recommendation](https://arxiv.org/html/2605.11447)：已有上下文门控、记忆融合及候选前缀相关输出评分。新增门控/前缀模块需解释区别，不应仅以模块名称作为论文贡献。
- [Preserving Item Semantics for Free: Rethinking Token Initialization in LLM-Based Generative Recommendation](https://arxiv.org/html/2608.07816)：已有语义中心初始化路线。保持其强基线地位有必要，单凭初始化加益或保护初始化无法认定创新。

## 预算和论文主张

沿用原 screen 三次推理，不增加完整查询矩阵。根据其结果只选择一条修正假设；首选梯度隔离分支若符合触发条件，最多新增一个20k-step训练条件，物理GPU0/1。失败后不自动再尝试PCGrad、动态门控或注意力。该上限是本次建议，不代表已经授权执行训练。

修正必须超过 A、解释新增/丢失路径，且在线机制在关闭对照下有可复现的净贡献；若只恢复到 A，得到的是训练副作用修复，尚未得到CGBS分支的必要性。任何正结果仍需独立评估、多seed与成本验证。

即使修正成功，论文也不能仅以“stop-gradient更好”作为主贡献。可检验的更窄叙事是：外部内容在有用的情况下提供补充决策信息，但全局item对齐可能影响原有生成表示；通过明确的梯度分工，在保留主干能力的同时利用这种互补性。其各段目前均需证据，不能把候选解释写成事实。
