# CGBS 状态门控：未决问题与第一版决策

## 决策状态

用户要求明确下一修正的未决部分与建议。本文件保留设计收敛依据；用户随后授权的 E 实现已进入独立变更 [`add-cgbs-state-dependent-gate`](../add-cgbs-state-dependent-gate/proposal.md)，工程交付以其 tasks/runbook 为准，科学效果仍待正式训练验证。证据依据为 `c-screen-outcome.md`、`c-signal-outcome.md` 与 D 的 `training-outcome.md`；本轮复核本地证据与可执行配置，没有重新查询不变的实验结果。

建议进入最小状态门控的规格、实现和轻量验证阶段，再交付一次 GPU0/1 手动训练。无需先展开更多通用冻结诊断，也不预先承诺门控一定改善。

## 尚未解决的科学问题

1. **主瓶颈归因**：全局层级alpha缺少状态适应能力是代码事实，但163新增/147丢失命中不证明这一限制就是主要原因；共同训练、模型评分错误也可能贡献损害。门控是待检验解释。
2. **可识别性**：归一化熵和JS差异是否包含“此时该相信哪条分支”的可用信息未知。熵低不等于正确；现有trace不包含每个候选状态的完整P/Q分布，不能据现有命中标签直接构造无泄漏的决策规则。神经网络置信度失准的风险已有研究支持，但不能将他人结果当作本项目门控有效性的证据：[Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html)。
3. **目标与使用分布**：保持原mixed generation CE会在正确父前缀上训练门控；真实beam会访问错误前缀。局部似然优化是否能改善最终top10未知。第一版保留原目标以隔离结构变化，不能同时加入ranking loss或beam训练来混淆结果。
4. **收益归因**：即便新模型超过C，也可能主要来自学到了不同的层级平均alpha或不同表示。需要结合独立训练的原C、同新checkpoint的常量干预和最终逐用户收益解释；门控均值/方差图不是必要性证明。

这些科学问题可以由一个设计明确的最小实验回答，无需在实现前再各开一轮实验。

## 第一版固定设置

| 项目 | 决定 |
| --- | --- |
| 修正单位 | 每个用户、当前父前缀、层级；输出一个共享给该父前缀所有合法子分支的混合权重 |
| 输入 | 生成分布P的归一化熵、内容分布Q的归一化熵、归一化JS(P,Q)，仅当前合法子分支 |
| 参数化 | `alpha_l = 0.5 * sigmoid(b_l + w_l^T stop_gradient(z))`；保留原4个b，每层新增3个w，总计新增12个参数 |
| 初始化 | w全零；b按原C初始化alpha=0.1。从同seed构造时初始打分和已有参数梯度与C一致，不宣称整个训练轨迹一致 |
| 梯度 | 仅门控输入z停止梯度；P/Q在混合概率中的原路径、辅助CE到query和encoder的原C路径均保留 |
| 层级 | 四层统一使用相同公式、各自参数；不预选某层硬开关或另设阈值 |
| 数值定义 | 合法子分支数K>1时熵除以log(K)，K=1时归零；JS除以log(2)；非法位置不计入，确保零概率有限 |
| 训练起点 | 同内容初始化、从头训练；不从已训练C再续20k，以免增加累计预算或混入不同训练起点 |
| 预算与优化器 | Beauty、seed42、GPU0/1、每卡batch128、20k steps、每500步验证、best validation NDCG@10；同原优化器、学习率及weight decay，不单设gate学习率 |
| 其他 | 四原型、temperature=0.1、辅助权重0.1、alpha上界0.5、beam10保持；不引入额外loss、teacher或新编码器 |

“梯度输入停止”与已失败的D不同：这里不隔离辅助CE，也不切断原Q到编码器的生成梯度。实现测试必须明确区分。

## 对照定义需要比上一稿更严格

第一关只做一个新训练，与已有A/C比较；同预算的原C就是独立训练的全局层级权重对照。

若出现值得追踪的改进，再对同一新best checkpoint做动态/常量配对。只把w置零会留下适应动态项后学到的b，不能将其称为“公平最优常量”。建议使用该checkpoint在**预先固定的训练样本**上的每层平均alpha作补充常量参考，且保留w=0为敏感性检查而非主要成功标准。均值仅使用训练数据，样本索引/seed/数量/前缀口径和checkpoint身份必须在实施规格中锁定；当前尚未实现该后续校准过程。

均值常量本身也不是最优常量，且训练前缀与beam前缀分布不同。动态胜过均值常量仅提供同checkpoint的状态依赖支持，应与新模型对独立训练C的比较共同解释，不能单凭一次关闭实验完成因果证明。后续机制确认不必在第一次训练前全部运行。

## 第一轮能作出的判断

| 结果 | 决策 |
| --- | --- |
| 新版本未改善C | 该门控参数化在当前预算下未获支持，不自动增加MLP/特征/seed |
| 超过C但低于A | 局部修正有效的候选信号，复杂分支仍未建立强基线上净收益，不进入论文主方法确认 |
| NDCG超过A/C但Hit下降 | 存在排序与覆盖交换，未通过原先Hit不下降门槛；不能隐藏该取舍 |
| NDCG超过A/C且Hit不下降 | 进入配对复算与动态/常量机制验证；单seed或微小峰值优势仍只是筛选信号 |
| 新版本有效且动态/常量、逐用户误伤证据一致 | 才考虑独立seed/数据集/未用于选型的最终测试；不立即宣称论文成立 |

新版本的训练best值与A/C训练best值同口径比较；后续推理统一用逐用户复算口径。预定前两层SID聚类bootstrap保持。报告最终收益、新增与丢失命中、路径到最终命中的连接及成本，不把“损失降低”“前缀更多”单独当作通过。
