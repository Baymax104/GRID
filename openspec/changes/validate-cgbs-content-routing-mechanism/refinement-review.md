# CGBS 复杂分支的修正研究

## 研究边界与结论

2026-09-16，用户明确要求固定 CGBS 方法与核心假设，研究参数、优化修正与必要模块。保留原来的判定事实：当前 C 未超过 A，尚不支持完整机制结论；将“当前版本未晋级”与“整个 CGBS 家族应停止”分开。

建议继续 CGBS，但首先研究辅助监督如何影响共享编码器。第一优先修改是只隔离辅助 item CE 回流至共享编码器的梯度，保留其训练 content query 的作用与原来的内容分支。暂不增加新方法名或多模块组合。

本轮读取现有代码、既有 W&B 训练证据、C 的真实 best checkpoint，并核验梯度恒等式；没有运行真实训练、推理或完整 diagnosis，没有修改生产模型。

## 代码与数学审查

### 1. 辅助 item CE 直接影响共享编码器

当前 `h=Encoder(history)`、`q=normalize(MLP(masked_mean(h)))`；总损失为 `L_mix + lambda L_item(q)`，lambda=0.1。辅助损失通过 q 回传 encoder 及共享输入表征，没有梯度隔离。

B 的主生成目标仍是合法 token CE。因此 B−A 的变化首先指向“增加辅助监督及其对优化轨迹的影响”，而不是在线分支复杂度。它还不能区分梯度方向冲突、过大的更新幅度、正则化偏差和训练随机性。

应测共享参数上的 `cos(g_gen,g_item)`、`lambda*norm(g_item)/norm(g_gen)`。损失数值8.5与1.9不是梯度范数，不能据此宣称辅助损失主导。梯度测量只能提供局部证据；真正的因果分离仍需要受控训练。

### 2. 混合 CE 改变了生成分支的直接训练信号

设 `P_y` 为合法 token 概率、`Q_y` 为内容概率、`M_y=(1-a)P_y+aQ_y`。当前生成项是 `-log M_y`，不是额外保留 `-log P_y`。

固定 Q 和 a 时，对 token logits z 的偏导为：

```text
∂[-log M_y]/∂z = r_y * ∂[-log P_y]/∂z
r_y = (1-a) P_y / ((1-a) P_y + a Q_y)
```

0<r_y<=1。Q 对目标越有信心，相同 P 下生成分支的直接梯度系数越小。例：a=0.2、P_y=0.1、Q_y=0.5时r约0.4444；极小 autograd 检查通过。

这是混合模型的正常责任分配，不是数值 bug，也不自动证明训练被损害；共享 encoder 还接收经由 Q 的梯度，上式不是完整 encoder 梯度。它提示：一旦测到严重共适应，可考虑保留纯 token CE 的辅助项，保护生成专家的独立能力。不能在未验证时同时修改 lambda、门控和损失。

### 3. 不应把 item CE 与 prefix 监督说成天然矛盾

对于固定全局 q、完整唯一 SID 和精确分支质量 `Z(p)=sum_{i in descendants(p)} exp(q·x_i/tau)`，条件概率是 `Q(c|p)=Z(pc)/Z(p)`。完整路径的概率乘积望远镜消去，恰好等于 item softmax。因此 exact item CE 等于完整路径各层 conditional CE 之和。

差别来自有限表示/优化、层权重、当前原型近似等，不能仅以“一个监督item、一个监督prefix”证明目标冲突。当前 generation_loss 对四层取均值，item CE 是整条路径尺度；调 lambda 时需要明确 reduction，但这个尺度差别也不能单独解释退步。

### 4. 两个有条件的结构瓶颈

- 当前 alpha 每层一个全局标量，同层所有用户和父前缀共用，不能按内容可靠性选择干预强度。这是设计限制，不是已证明的失败原因。
- query 是历史 encoder 输出的 masked mean，经同一个 MLP 产生；同一用户所有前缀复用 q。后代集合仍使内容概率随 prefix 改变，故不能声称模型完全不理解前缀。若真实 query 缺乏纠错信号，才考虑更合适的 pooling 或 decoder-state-conditioned query。

原型质量与全目录 item CE 使用的精确打分不同。若 exact 与 prototype 的 branch 排序显著不同且 exact 真实净收益更好，才定位为近似问题。不能因多个原型未赢，就直接从4增到16或32。

## 调参、修正、模块的优先顺序

| 方向 | 针对的问题 | 最小动作 | 优先级与条件 |
|---|---|---|---|
| 辅助梯度隔离 | 辅助监督牵动共享表征 | 只在辅助CE路径对h做stop-gradient，MLP照常训练 | 第一优先；不增加可训练参数，直接拆解B的负向信号 |
| lambda | 辅助目标更新过强 | 以已测梯度量级选择一个较弱权重，如0.03；不预设其最优 | 若不做梯度隔离，可作为替代首项；不得同轮一起改 |
| alpha初值/介入时机 | 未学好的分支过早参与 | 更小初值或短warm-up | 权重/质量早期轨迹支持时；不是先扩大alpha上限 |
| 纯token CE约束 | 混合专家共适应导致AR能力下降 | 保留L_mix并增加beta L_token | 测到直接梯度衰减与off退步后才做，不能用其替代第一项归因 |
| 轻量可靠性门控 | 同层不同用户需要不同融合 | 小门控依赖历史/decoder状态及两分布统计 | 只有内容已能纠错但误伤集中时；相同信息量控制参数效应 |
| query改进 | 均值query缺少有用信号 | 先换一种pooling，再考虑prefix-conditioned query | exact内容本身没有足够纠错信号时 |
| 原型数量/近似 | 集合质量的压缩误差 | 对照exact，按误差证据修复 | 当前不优先，无已证实的多原型收益 |

temperature同时影响辅助监督梯度和分支分布尖锐度，单独扫它也会同时改变两个环节。若研究温度，需要区分训练item温度与推理分支温度，并在config记录；不能同时调整lambda后仍把收益归于其中之一。

## 首选修正的精确定义

保留同一个 query MLP，区分其两条计算路径：

```text
q_mix = normalize(g_phi(h_theta))
q_aux = normalize(g_phi(stop_gradient(h_theta)))
L = L_mix(P_theta, Q(q_mix)) + 0.1 L_item(q_aux)
```

辅助CE仍更新phi，但不直接更新theta；混合生成损失仍可以经P与Q两路更新theta。这个设计不等于detach(q)，后者会让辅助CE连query都无法训练；也不等于冻结整个encoder。前向数值应与原C一致，变化只在反向路径。

首个新条件应只改这一点，复用原C超参数、预算、初始化和checkpoint选择。诊断记录共享梯度方向/量级及纯token损失；最终仍需同时比较A、C和修正C，不把只超过C视作论文成功。

如果恢复了AR能力但Q变弱，结论是完全隔离过强；可在同一机制内研究有限梯度回流或逐步解冻，不换主方法。若AR能力未恢复，需检验mixed CE路径而不是继续调lambda。

## 必要模块的具体候选

若冻结推理证据显示同一内容分支能救回一部分用户、同时误伤另一部分，最有针对性的新增模块是每用户/前缀的轻量门控，而非新的大编码器：

```text
a_l(u,p) = a_max * sigmoid(b_l + g_l(state, entropy(P), entropy(Q), disagreement(P,Q)))
```

g最后一层零初始化可使初始行为回到原有层级常数门控；这是初始等价，不是训练后不退步保证。输入不包含目标标签。熵低不代表正确，门控必须由训练数据学得，并在真实推荐结果上验证。需要常量门控对照和真实内容对应关系对照；不能仅凭门控可视化说机制有效。

如果内容本身没有有用互补信号，门控只能减少损害，不能凭空创造信息。因此不能把门控作为当前所有问题的通用答案。

## 相关工作核对与限制

这是针对现有CGBS的定向研究，不是穷尽文献综述。

- [Gradient Surgery for Multi-Task Learning, NeurIPS 2020](https://arxiv.org/abs/2001.06782)：说明共享任务梯度的干扰是可研究的优化问题；不证明本项目已有同样干扰。先测梯度，当前不引入PCGrad实现。
- [GradNorm, ICML 2018](https://proceedings.mlr.press/v80/chen18a.html)：基于梯度量级进行多任务损失平衡，支持不能只看loss标量来判断权重；不保证适用于当前推荐任务。
- [LIGER](https://arxiv.org/html/2411.18814v2)：联合item内容目标和SID生成目标，提醒辅助监督并非天然有害。其输入、目标与推理设计不同，不能直接移植超参数或当作CGBS对照。
- [ReZero](https://arxiv.org/abs/2003.04887)：零初始化残差门控可改善其研究设置中的优化。这里只借鉴“增量初始化不扰动已有路径”的设计思想，概率门控不是同一模型，不能宣称同样保证。

梯度隔离、门控和loss balancing均有既有工作。论文贡献不能只是添加detach或一个MLP；仍应是内容聚合在SID早期分支决策中的机制与质量/成本证据，修正负责让该机制得到公平检验。
