# Beauty五seed冻结testing结果

## 决策

本轮未通过testing-plan.md预定门槛：A相对匹配深层残差平均NDCG@10正0.752%，但仅3/5 seed为正；去掉seed44后均值变负。训练seed和用户prefix-cluster两类区间均跨零。结论降级为“完整内容与匹配残差初始化的测试差别尚未明确”，不宣称等价，也不宣称残差更优。停止以此优势为依据扩展数据集/seed，不自动训练embedding预热。

这不是对“内容初始化相对随机初始化有益”的否定：本轮两个条件都使用内容相关初始化，且共用A首层。该更宽命题需要匹配随机初始化对照，不能借本轮结果直接证明或否定。

## 在线与逐用户核验

按testing_protocol=beauty-sid-five-seed-v1查询，恰好十项，全部finished，五seed×两条件无缺失、无重复。每项22363个唯一用户，十项用户集合和完整目标SID标签逐位一致。每用户10个唯一合法物品SID，标签本身合法，预测命中/排名与trace最终层逐位一致，prefix生存无失败后复活。共5196个目标前两层SID cluster。

配置核验testing、beam10、sequence_length180、四层SID、codebook256、原模型模式、非dry-run、相同完整data config。Trainer为单GPU、32-true，无limit_predict_batches等截断。预测/trace经共享loader读取。实际checkpoint lineage与testing-frozen-manifest.json十个digest逐一匹配；SID/content digest匹配，残差量化器digest312fbcb197a710aaa6f40f36d1e0a08f匹配。trace目录fingerprint一致，metadata的split和checkpoint URI一致。本地冻结文件hash无变化。

历史TIGER基线曾使用testing；用户已确认仅用于报告基线，没有用于选择A/残差及超参数。本轮称独立于这两个方法选择的冻结测试评估，不称项目首次盲测。未对远端数据生成过程做逐样本时序泄漏审计。

## 不确定性与敏感性

NDCG绝对平均差0.000224285，成对seed差样本标准差0.001097308。

| 估计对象 | NDCG差95%区间 | Recall差95%区间 |
| --- | --- | --- |
| 五个成对训练seed，探索性t区间(df=4) | [-0.00113820, 0.00158677] | [-0.00116869, 0.00267117] |
| 固定五对模型的用户差，prefix-cluster bootstrap | [-0.00052790, 0.00096762] | [-0.00060653, 0.00198704] |

bootstrap按目标前两层SID聚类，2000次、seed42。第二行条件于已训练五组模型，不覆盖完整训练随机性。第一行仅五个重复，分布假设与小样本限制必须披露；两类区间均不能证明等价。每个seed单独的用户cluster区间也都跨零，详见analysis.json。

移除seed42/43/44/45/46后的NDCG平均差依次为0.000031168、0.000382038、-0.000039635、0.000124527、0.000623329。预定“leave-one-seed-out均值仍正”条件未满足，不据此删除seed44或46后另立主结论。

## 下一步边界

1. 固定并完整报告本结果，不继续在Beauty testing上选方法、调eta/预热或挑checkpoint。
2. A可以作为工程默认实现保留；论文暂不能主张完整内容均值稳定优于匹配残差，也不能把泛化波动直接写成已证实的可修复瓶颈。
3. 如继续当前课题，先只读盘点随机初始化基准是否与A具有相同合法前缀约束、数据、预算和选择规则，确认“内容初始化整体增益”证据缺口；不自动补训练。历史不匹配基准不能直接填入主表。
4. 任何未来根据本轮testing结果形成的新机制，不能再使用该testing作为从未参与开发的确认集；需要新的独立验证依据。

本轮只读获取已有产物并进行本地统计，未启动训练/推理、未修改生产代码或创建W&B run。
