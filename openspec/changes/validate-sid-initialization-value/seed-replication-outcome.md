# Beauty三seed成对复核结果

## 判断

固定A的完整内容初始化在seed42、43、44的最佳val NDCG@10均高于固定深层残差方案；两个新增seed的优势分别0.96%、2.25%，低于初始seed42的4.82%。三个seed的19000步、20000步及最后5次验证均值也均为正差。主线可继续固定为A，但收益幅度应下调为当前三seed均值约2.69%，不能将4.8%描述为稳定典型收益。

两个新seed在最佳NDCG checkpoint对应Recall上略低于残差方案，因此只支持NDCG排名质量方向一致，不支持所有指标均稳定提高。三seed不足以建立强跨seed显著性；此次没有新增独立测试证据。

## 完整性与实现冻结

2026-09-17只读获取W&B六个run的config、summary、完整history、输入输出artifact。四个新run及两个参考均finished，验证从500至20000步各40次；所有残差run使用正确量化器digest `312fbcb197a710aaa6f40f36d1e0a08f`，六项共用相同SID/content digest。

逐字段核对模型、数据、trainer和callbacks：除训练seed、预定初始化模式/码本配置及输出路径/任务名称外，未发现额外差异。每卡batch128、lr0.0005、双卡、20k steps、每500step验证、bank_seed42及checkpoint规则不变，从头训练，非dry-run。seed43两条件均记录GPU4/5，seed44两条件均为GPU6/7。

## 主方法与下一步

现在可以停止Beauty上的方法搜索和训练调参，将A固定为主方法版本。合适的工作叙事是：SID量化码的残差代表量与生成token的初始化需求不完全一致，完整物品内容的条件均值在当前匹配方案下带来可重复的NDCG改善。该表述仍应限定为目前Beauty三seed，不声称纯语义因素被完全隔离或各指标普遍改善。

下一步优先使用现有六份最佳checkpoint在未参与选择的testing划分统一评估，保持beam和协议不变；无需新增训练，也不必为重复确认同一validation标量再跑一轮evaluation。随后才判断是否进入固定第二数据集复核。不追加seed45/46，不恢复C/D/E，不基于此次Recall下降临时加模块或改目标。testing评估尚未实施或启动，须由用户手动执行后才能形成独立测试证据。
