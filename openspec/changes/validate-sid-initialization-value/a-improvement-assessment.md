# 在固定A基础上继续改进的理论评估

## 判断与证据等级

可以继续研究A，但五seed仅说明相对匹配残差方案有小幅平均NDCG优势（约1.80%，4胜1负），不能推导出某个新模块必然有效。本轮只核查源码、文献和既有固定目录统计，不改模型，不启动训练。

建议只保留一个新增候选：深层完整内容均值的范数校准。它保留A的内容来源、同码分组及方向信息，检验内容一致性隐含的径向权重是否适合推荐优化。其效果仍是未验证假设，不将静态范数差异本身认定为已证实瓶颈。

## A的理论边界

当前A：x_i=normalize((z_i-m)P)，mu_lk=mean(x_i | k_l(i)=k)，e_lk=s_l*mu_lk。P固定，s_l按全层随机表与均值表的population std匹配。三个语义层初始化，最后去重层随机，所有token继续学习。

mu是该目录同码物品在x空间中的常量平方重建误差最优解。任意v满足mean||x-v||²=mean||x-mu||²+||v-mu||²。这个性质只适用于未缩放mu和该重建目标，不证明NDCG最优。因此，优化方向应是改变初始化先验的表达或强度，而不是声称均值计算错了。

特别地，均值覆盖整个固定目录，不能无依据地套用“小样本估计误差”把它当有噪总体均值估计；训练交互不足和目录统计不确定性也不是同一件事。相同token跨父前缀池化是事实，但新建父前缀模块会改变表示和计算规模，本轮不优先考虑。

## 可核查结构：方向与范数耦合

令mu=r*u，||u||=1。对于n个单位内容向量：

```text
r² = ||mean(x_i)||²
   = (1/n²) * sum_ij <x_i,x_j>
   = 1/n + (n-1)/n * mean_{i!=j}<x_i,x_j>   (n>1)
```

所以r受同码物品的一致性和目录占用数量共同影响，n=1时r=1。它不是行为重要性、用户偏好或统计置信度的校准量。A按同层共同s缩放后，r的相对比值仍保留在token输入embedding中。共享标准差不等于各token等范数。

本轮从既有checkpoint中的固定catalog.features/sids读取（不用训练后的token权重），每层256码等权统计：

| 语义层 | 范数P10 | 范数中位数 | 范数P90 | P90/P10 | 范数变异系数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 0.69299 | 0.78574 | 0.89333 | 1.289 | 0.101 |
| 2 | 0.35096 | 0.55050 | 0.84109 | 2.397 | 0.321 |
| 3 | 0.23679 | 0.39444 | 0.75465 | 3.187 | 0.449 |

目录占用数量与范数的Pearson相关分别约−0.171/−0.678/−0.749。这里只是目录项数，不是交互频次，不能称为流行度偏差。后两层存在明显径向差异是已测事实；它是否有害尚不明确。

不能直接宣称大范数导致更大输出logit或更高推荐概率：当前SID输入表与lm_head不是简单绑定，Transformer归一化、残差结构和后续训练会共同影响其作用。范数可能是有用的内容一致性信号，也可能造成不合适的优化先验，两种解释都需保留。

## 一个针对性机制

只改第2、3层，首层和去重层保持A：

```text
v_lk(eta) = ||mu_lk||^eta * mu_lk / ||mu_lk||
e_lk(eta) = std(random_layer) / std(V_l(eta)) * v_lk(eta)
```

eta=1严格还原A；eta=0对非零码完全等范数；建议首个候选固定eta=1/2，压缩而不完全删除一致性差异。零向量保留为零，近零向量须明确数值处理，不盲目除以极小数。

正范数下，所有token方向及码间余弦相似度不变，范数比从r_a/r_b变为(r_a/r_b)^eta。P90/P10预期由2.40/3.19压缩为约1.55/1.79。保留A的全层std匹配、不新增参数/损失/在线内容计算。全层均值和欧氏距离可能随径向变化而改变，不能声称所有几何量均不变。

这是范数校准的可检验构造，不是推荐风险最优定理。它会提高相对小范数码的权重，也可能放大混合父前缀下不可靠的均值方向；不存在无条件更优保证。

## 选择与不选择

- 优先：深层范数校准。改动与已测结构直接相关，保留方向，失败后可完整回到A。
- 暂缓：额外语义正则/冻结或慢学习。可能抑制行为适配，目前没有证据说明有害的语义遗忘是瓶颈。
- 暂缓：按交互频次加权均值。改变语义目标且可能引入热门偏向；尚无目标分布失配的直接证据。
- 暂缓：父前缀条件化、多原型、内容门控。需要新表示或在线分支，复杂度和归因成本较高，不能由当前小幅收益直接推出必要性。

## 有限实验建议与停止规则

本轮不自动实施。若用户采纳，只增加一个预先固定eta=1/2的深层校准版本，先用seed45、46各一项，共两次训练，复用同seed既有A。选择它们是为了针对已观察到的失效/不稳定案例做诊断，不是无偏跨seed效果估计。

实现前轻量检查：eta=1逐位复现A；eta=1/2保持首层/去重/未用码及随机流；核验深层方向/余弦保持、范数比压缩、全层std匹配和梯度有限。

沿用既有20k训练和best-val NDCG主指标，同时看20000步和后5点均值。要求两个诊断seed均超过各自A，且后段改善不只依赖峰值，才进入补齐原五seed的确认；不据这两个针对性选取的seed直接写论文收益。若一正一负或仅微小峰值改善，视为未建立机制价值，不继续自动扫eta或追加模块。Recall单列，不能只报告有利指标。

模型开发期间继续保留testing作最终评估；若选择继续改A，应在版本和验证集选择规则锁定后统一打开testing，避免一边用测试集判断一边继续调参。保持原A为固定对照。

## 文献与创新边界

[Preserving Item Semantics for Free](https://arxiv.org/html/2608.07816v1)已研究残差码本质心用于SID token初始化；[Grounded Token Initialization](https://arxiv.org/abs/2604.02324)也研究生成推荐新token的语义初始化问题。因此不能将“语义初始化”或“归一化”本身作为充分新颖性声明。此次建议的意义取决于是否证明A中内容一致性与初始化强度的耦合在当前场景造成可修复限制，并取得重复的实际推荐增益。尚未完成针对范数校准的穷尽文献检索，不声称首创。
